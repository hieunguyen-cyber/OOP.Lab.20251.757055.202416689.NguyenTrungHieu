\f0\b\fs36 \cf2 Question:
\f1\b0\fs42 \
If you create a constructor method to build a DVD by title then create a constructor method to build a DVD by category. Does JAVA allow you to do this?\
\

\f0\b\fs36 Answer:
\f1\b0\fs42 \
No, Java does not permit that. Both constructors would have identical parameter types and counts, so the compiler would not be able to distinguish between them. As a result, they cannot coexist \'97 constructor overloading requires a difference in parameter list (number or types).}
