Question:  
If you create a constructor method to build a DVD by title then create a constructor method to build a DVD by category. Does Java allow you to do this?  

Answer:  
No, Java does not permit that. Both constructors would have identical parameter types and counts, so the compiler would not be able to distinguish between them. As a result, they cannot coexist — constructor overloading requires a difference in the parameter list (number or types).
