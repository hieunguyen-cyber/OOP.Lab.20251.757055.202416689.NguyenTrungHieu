3. Is JAVA a Pass by Value or a Pass by Reference programming language?
Java is pass by value. It always passes a copy of the variable’s value. For objects, this value is a copy of the reference, not the object itself.

- After calling swap(jungleDVD, cinderellaDVD), the titles stay the same because Java passes copies of the references — swapping those copies doesn’t affect the original variables.
- After calling changeTitle(jungleDVD, cinderellaDVD.getTitle()), the JungleDVD’s title changes because the method modifies the object’s internal state through the copied reference, which still points to the same object in memory.

The code for the new swap() function that works is in the test file. Since only the title is set in the code, we only need to swap the title (other attributes are not set so they would not matter)
Here's a code that swap all attributes entirely:
public static void swap(DigitalVideoDisc d1, DigitalVideoDisc d2) {
    String tmpTitle = d1.getTitle();
    String tmpCategory = d1.getCategory();
    String tmpDirector = d1.getDirector();
    int tmpLength = d1.getLength();
    float tmpCost = d1.getCost();

    d1.setTitle(d2.getTitle());
    d1.setCategory(d2.getCategory());
    d1.setDirector(d2.getDirector());
    d1.setLength(d2.getLength());
    d1.setCost(d2.getCost());

    d2.setTitle(tmpTitle);
    d2.setCategory(tmpCategory);
    d2.setDirector(tmpDirector);
    d2.setLength(tmpLength);
    d2.setCost(tmpCost);
}
